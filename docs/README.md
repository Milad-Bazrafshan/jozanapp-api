## وضعیت فاز صفر

تصمیم‌های پایه زیر تثبیت شده‌اند:

1. محصول یک سامانه مستقل مدیریت مراکز آموزشی است.
2. مدرسه، آموزشگاه زبان، کنکور و فنی‌وحرفه‌ای از یک هسته عمومی استفاده می‌کنند.
3. هر مشتری یک Tenant مستقل و هر شعبه زیرمجموعه مؤسسه آموزشی است.
4. نسخه اول برای یک مؤسسه مستقل عرضه می‌شود، اما مرز Tenant از اولین Migration اعمال خواهد شد.
5. Backend یک Modular Monolith با Java و Spring Boot است.
6. Frontend با React و Vite در دو برنامه مدیریتی و کاربری ساخته می‌شود.
7. Orix Bank جزئی از دامنه این محصول نیست و در آینده فقط از طریق درگاه کیف پول/پرداخت متصل می‌شود.
8. حسابداری محصول داخل همین سامانه توسعه می‌یابد؛ MVP فقط عملیات مالی آموزشی را پوشش می‌دهد.

## شرط ورود به فاز یک

فاز یک می‌تواند با تصمیم‌های فعلی شروع شود. موارد باز در اسناد با برچسب `Open` مشخص شده‌اند و مانع ساخت زیرساخت نیستند، اما باید پیش از پیاده‌سازی ماژول مربوطه تعیین تکلیف شوند.
