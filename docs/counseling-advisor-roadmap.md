# ماژول مشاوره — نقشه راه

**وضعیت:** فاز ۱–۳ (تخصیص، گزارش روزانه، برنامه درسی + تیک) در backend و UI اولیه پیاده شد. Job ماهانه + AI و گسترش چت در فاز بعد.

این سند نیازمندی‌های محصولی شما را برای **ارتباط مشاور–دانش‌آموز، گزارش کار، سلسله‌مراتب مشاور، برنامه درسی** جمع‌بندی می‌کند.

## سلسله‌مراتب مشاور

| سطح | کد پیشنهادی | ارتباط مجاز |
|-----|-------------|-------------|
| مشاور ارشد | `COUNSELOR_SENIOR` | همه مشاوران + دانش‌آموزان تحت پوشش سازمان |
| مشاور میان‌رده | `COUNSELOR_MID` | فقط **اولیا** |
| مشاور پایین‌رده | `COUNSELOR_JUNIOR` | فقط **دانش‌آموز** |

- نقش‌ها در `organization` (AccessRole + Permission) تعریف می‌شوند.
- هر API با `@PreAuthorize` + `ScopeAuthorizer` (رابطه مشاور–دانش‌آmoز/ولی) محافظت می‌شود.

## گزارش کار دانش‌آموز → مشاور اختصاصی

- دانش‌آموز هر روز (یا بازه دلخواه) **قالب ثابت** پر می‌کند: فعالیت‌ها، مدت، درس، یادداشت.
- فقط مشاور assign‌شده به آن دانش‌آموز دسترسی read/write دارد.
- وضعیت: پیش‌نویس / ارسال‌شده / بازخورد مشاور.

## گزارش مشاور → ادمین

- مشاور هر زمان (روزانه/هفتگی/ماهانه) گزارش کلی برای ادمین می‌فرستد.
- ادمین در پنل admin لیست و جزئیات + فیلتر مشاور/بازه.

## گزارش خودکار ماهانه → مشاور ارشد

- Job ماهانه (Outbox/worker داخل monolith) تجمیع گزارش‌های مشاوران زیرمجموعه.
- قبل از ارسال: **پیش‌نمایش + تحلیل AI اختیاری** (پورت integration؛ متن گزارش به provider؛ بدون ذخیره secret در front).
- مشاور ارشد تأیید/رد یا ویرایش قبل از نهایی‌سازی.

## برنامه درسی + تیک پیشرفت

- مشاور برای دانش‌آموز **برنامه** (درس، مدت هدف، بازه تاریخ) می‌سازد.
- دانش‌آموز آیتم را «انجام شد» با **مدت واقعی** (مثلاً ۲ ساعت) علامت می‌زند.
- مشاور پیشرفت را در پنل instructor/admin می‌بیند.

## ارتباط (چت)

- ماژول `chat` موجود است؛ برای مشاور–دانش‌آmoز channel اختصاصی با همان قواعد scope گسترش می‌یابد.

## UX (هر ۳ پنل)

- عنوان صفحه + یک خط «این صفحه چه کاری انجام می‌دهد».
- خالی بودن لیست: راهنمای گام بعد (مثلاً «ابتدا مشاور را از پنل مدیر assign کنید»).
- تاریخ/زمان با locale fa/en (همان الگوی `formatDateTime`).

## مهاجرت DB

- Flyway `V12__counseling.sql`: جداول `counselor_assignment`, `student_daily_log`, `counselor_report`, `study_plan`, `study_plan_item`, `study_plan_progress` + `tenant_id` روی همه.

## اولویت پیاده‌سازی پیشنهادی

1. نقش‌ها و assign مشاور به دانش‌آmoز  
2. گزارش روزانه دانش‌آmoز + inbox مشاور (client + instructor)  
3. برنامه درسی + تیک  
4. گزارش مشاور به admin  
5. تجمیع ماهانه + hook AI
