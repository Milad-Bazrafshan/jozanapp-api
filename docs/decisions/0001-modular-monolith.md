# ADR-0001: Modular Monolith

- وضعیت: Accepted
- تاریخ: 2026-09-15

## زمینه

محصول دامنه‌های متعدد و مرتبط دارد، تیم و بار واقعی هنوز تثبیت نشده و تراکنش‌های ثبت‌نام، جلسه، آزمون و مالی به هماهنگی نیاز دارند.

## تصمیم

Backend به‌صورت یک برنامه Spring Boot با ماژول‌های دامنه‌ای مستقل ساخته می‌شود. هر ماژول مالک داده خود است و API عمومی مشخص دارد.

## پیامدها

- استقرار و تراکنش‌های نسخه اول ساده‌تر می‌شوند.
- مرز ماژول‌ها با تست معماری کنترل می‌شود.
- استخراج سرویس مستقل فقط با شواهد بار، تیم یا چرخه انتشار انجام خواهد شد.
