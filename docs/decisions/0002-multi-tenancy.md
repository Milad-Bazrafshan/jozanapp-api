# ADR-0002: Shared Schema Multi-Tenancy

- وضعیت: Accepted
- تاریخ: 2026-09-15

## زمینه

نسخه اول برای یک مؤسسه مستقل است، ولی محصول باید بدون بازطراحی اساسی به چند مشتری مستقل عرضه شود.

## تصمیم

یک دیتابیس و schema مشترک استفاده می‌شود و تمام داده‌های تجاری `tenant_id` دارند. Tenant Context از عضویت احراز‌شده ساخته می‌شود.

## پیامدها

- هزینه عملیاتی MVP پایین می‌ماند.
- تمام Queryها، Constraintها، jobها و تست‌ها باید Tenant-aware باشند.
- مهاجرت یک Tenant به دیتابیس جدا در آینده به ابزار export/import کنترل‌شده نیاز خواهد داشت.
