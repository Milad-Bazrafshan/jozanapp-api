# ADR-0004: جداسازی کلاس، برنامه و جلسه

- وضعیت: Accepted
- تاریخ: 2026-09-15

## زمینه

یک کلاس ممکن است چند استاد، زمان و محل داشته باشد و یک جلسه خاص لغو، جابه‌جا یا با استاد جایگزین برگزار شود.

## تصمیم

`ClassSection` هویت گروه اجرایی، `ScheduleRule` الگوی تکرار و `ClassSession` رخداد واقعی یک تاریخ است. استاد و محل در سطح Rule و Session قابل تخصیص هستند.

## پیامدها

- تغییر یک جلسه Rule اصلی را تغییر نمی‌دهد.
- حضور، گزارش جلسه و حق‌التدریس آینده به Session متصل می‌شوند.
- تولید و به‌روزرسانی جلسات باید idempotent و آگاه از Override باشد.
